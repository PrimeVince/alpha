# Alpha — JavaScript Practice Exercises

A collection of small browser-based exercises created while learning JavaScript and the Document Object Model (DOM).

## What is included

The repository contains individual HTML, CSS and JavaScript files covering beginner concepts such as:

- Variables, values and basic expressions
- Conditional logic and switch statements
- Comparison and logical operators
- Loops and iteration
- String and number operations
- DOM interaction through inputs, buttons and displayed results
- A simple interactive counter

Each exercise is kept as a small standalone page so that the concept can be explored independently.

## Technologies

- HTML5
- CSS3
- JavaScript (vanilla)

## Run an exercise

1. Clone or download the repository.
2. Open an exercise file such as `counter.html`, `case.html` or `checks.html` directly in a browser.
3. Use the page controls and inspect the corresponding JavaScript file to see how it works.

There is no build process or package installation.

## Project status

This is an early learning collection, not a finished application. File names and exercise interfaces reflect the original practice work. The examples are retained as a record of learning JavaScript fundamentals and will be improved over time.
